# 두레이더(DU Radar) 비교조사

2026-09-18 새벽에 조사했다. 발표에서 비슷한 서비스와 뭐가 다른지 말하려고 찾아본 것이다.
표기 규칙: 웹에서 확인한 내용만 사실로 적고, 확인 못 한 것은 "확인 안 됨", 짐작은 "추정"으로 표시한다.

두레이더 요약: 대구대 경산캠퍼스 지도 위에 핀을 찍어 학교 정보를 모으는 커뮤니티 웹앱. 소식(사업단·기관 공지를 건물 핀에), 편의시설(라운지·카페·편의점 41곳), 분실물, 고장 제보, 운동장·테니스장 예약. 로그인 없음, 개인정보 없음, 기기 식별자만.

### 2-2. 캠퍼스 지도 형태

- 공식 캠퍼스지도 페이지(홍보관 > 캠퍼스투어 > 캠퍼스지도): https://www.daegu.ac.kr/page/54
- 형태: PDF 파일 한 장. https://www.daegu.ac.kr/data/pdf/2025_daegu_campus.pdf (약 360KB)
- 내용: 건물 번호 체계 있음(E1-1, W2-1처럼 동·서 구분 + 숫자). 약 30개 이상 건물명 표기. 카페·편의점 같은 편의시설은 표기되지 않음.
- 클릭·검색·길찾기 없음. 카카오/네이버 API 미사용.
- 장애인 편의시설 지도도 PDF로 따로 제공. VR 투어는 외부 사이트 링크.
- 대구대 공식 앱(App Store id6473981107, Google Play kr.ac.daegu.smart)은 학사공지·종합정보·전화번호·셔틀버스·도서관 메뉴를 제공하며 학번 인증이 필요하다. 지도 기능 유무는 확인 안 됨.

### 2-3. 편의시설 안내

- 커뮤니티 > 학생복지 > 편의 복지시설: https://www.daegu.ac.kr/article/DG200/list
- 편의점·카페·FOOD·복사/서점·문구/잡화·금융/우편·안경·세탁/꽃·사진관·기타 10개 카테고리, 4페이지 분량.
- 시설명만 텍스트로 나열. 위치 설명·지도 없음.
- 가장 최근 글이 2022-12-28, 오래된 글은 2018-10-22. 최신성 관리가 안 되고 있음.

### 2-4. 분실물

- 커뮤니티 > 게시판 > 분실물/습득물: https://www.daegu.ac.kr/article/DG176/list
- 학생 개인이 글을 올리는 일반 게시판. 2026-09에도 글이 올라오고 있고(전자부품 상자, 카드지갑, 애플펜슬 등) 8페이지 이상 누적.
- 위치·지도 없음. 사진은 일부 글만 첨부. 글쓰기 로그인 필요 여부는 확인 안 됨(추정: 필요).
- 학교 차원의 습득물 보관소 안내 페이지는 확인 안 됨.

## 3. "학생이 학교 정보 찾기 어렵다"를 뒷받침하는 자료

정량 수치 중 "공지를 놓친 학생 N%" 같은 직접 통계는 확인 안 됨. 아래는 간접적으로 뒷받침하는 자료다.

1. 한국핀테크연구회·여의도아카데미 2021년 2월 설문: 대학생 필수 앱 1위 에브리타임 94.4%. 같은 기사에서 카더라 게시물과 익명 비방 문제를 지적. 학교 공식 채널보다 커뮤니티에 정보가 몰려 있고, 그 커뮤니티의 신뢰도는 낮다는 근거로 쓸 수 있다.
   - 경남신문 2021-05-27: https://www.knnews.co.kr/news/articleView.php?idxno=1352059
   - ITWorld Korea(같은 설문 보도): https://www.itworld.co.kr/t/40/%EC%98%A4%ED%94%BC%EC%8A%A4%EF%BC%86%ED%98%91%EC%97%85/184419
2. 한국도서관·정보학회지 52(3), 2021, "온라인 커뮤니티 에브리타임을 통한 대학생의 일상정보 이용행태에 관한 연구": 면담 결과 학생들이 학사일정·수업정보·졸업정보 등 학교 생활 정보를 얻는 데 에브리타임을 가장 많이 이용하고, 코로나 시기 입학한 1·2학년은 의존도가 특히 높았다. 질적 연구라 비율 수치는 없음.
