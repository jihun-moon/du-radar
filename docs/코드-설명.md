# 코드 설명

코드는 짓다에서 나온 것이다. 대회가 끝나고 읽어 보면서 정리했다.

## 폴더

```
app/
  server.js          서버. node 에 들어 있는 모듈(http, fs, path)만 쓴다
  public/            브라우저로 나가는 파일
    index.html       화면 뼈대
    app.js           화면 동작 전부 (175KB)
    app.css          화면 색과 배치
    map-style.css    지도 색
    service-worker.js  인터넷이 끊겨도 지도는 열리게 하는 캐시
    data/            지도와 기능별 데이터
    vendor/          Leaflet(지도), qrcode(QR)
  store/             서버가 쓰는 저장 파일. 밖에서 안 열린다
  test/              서버 시험
  AGENTS.md          짓다에 적어 둔 작업 규칙
```

패키지를 설치하지 않는다. 돈이 들거나 키가 필요한 지도와 API 는 안 쓰기로 처음에 정했다.

## server.js (317줄)

정적 파일, API, 입력 검사, 저장이 한 파일에 있다.

`public/` 안의 파일만 내보낸다. 주소에 `..` 이 있거나 풀어 본 경로가 `public/` 밖이면 404 다. 그래서 `/server.js` 나 `/store/pins.json` 은 밖에서 안 열린다.

API 는 일곱 개다.

| 주소 | 무엇 |
|---|---|
| `/api/pins` | 사용자가 찍은 핀. 편의시설, 분실물, 제보 세 종류만 받는다 |
| `/api/reports` | 핀 신고. 기기당 한 번, 세 기기가 신고하면 핀을 숨긴다 |
| `/api/reactions` | "나도 겪었어요". 기기당 한 번 |
| `/api/spot-suggestions` | 편의시설 "위치가 달라요" |
| `/api/reservations` | 운동시설 예약과 취소 |
| `/api/posts` | 글 저장 |
| `/api/weather` | open-meteo 에서 현재 날씨를 받아 10분 동안 들고 있는다 |

막는 것들.

- 캠퍼스 경계에서 300m 를 더한 범위 밖 좌표는 400
- 주소, 메일, 전화번호, 학번(글자 "학번"이나 숫자 8자리)이 들어간 글은 400
- 같은 기기가 같은 글을 1분 안에 또 올리면 429, 1분에 5개를 넘겨도 429
- 핀 목록을 내줄 때 기기 번호는 뺀다. 내 기기 번호를 같이 보내면 내 핀에만 표시가 붙는다
- 예약은 같은 시설, 같은 날, 같은 시간이 이미 있으면 409. 한 기기가 하루 2개를 넘기면 429. 남의 예약을 취소하려 하면 403

저장은 `store/` 의 JSON 파일이다. 임시 파일에 먼저 쓰고 이름을 바꿔 끼운다. 쓰는 도중에 서버가 꺼져도 파일이 깨지지 않게 하려는 것이다.

## public/app.js

기능을 하나씩 덧붙여 가며 만든 코드라 한 줄이 아주 길고 읽기 좋지는 않다. 나누면 이렇다.

- 지도. Leaflet 위에 `campus-map.json` 의 건물, 길, 물, 녹지를 직접 그린다. 지도 타일 서버를 안 쓴다
- 핀. 종류마다 색과 아이콘이 다르다. 많이 겹치면 숫자 동그라미로 묶이고 확대하면 풀린다
- 패널과 시트. 컴퓨터와 태블릿은 왼쪽 패널, 폰은 아래에서 올라오는 시트다. 시트는 세 높이에서 멈춘다
- 카드. 목록에서 글을 누르면 그 자리에서 펼쳐지고 지도가 그 위치로 가면서 건물 윤곽이나 운동장 테두리가 잠깐 강조된다
- 핀 찍기. 더하기 버튼, 지도를 끌어 위치 맞추기, 종류 고르기, 글, 올리기
- 오른쪽 위 레이어 버튼. 핀 종류 다섯 가지를 체크해서 보이고 숨긴다
- 한/영. 화면 글자를 두 벌 가지고 있고 고른 언어를 기억한다
- 기기 번호. 처음 들어올 때 브라우저에 무작위 값을 만들어 둔다. 로그인 대신 이걸로 "내 핀"과 "한 번만"을 구분한다

## 데이터

| 파일 | 무엇 |
|---|---|
| `campus-map.json` | 건물, 길, 물, 녹지, 캠퍼스 경계. OpenStreetMap |
| `events.json` | 기관 5곳과 공지 24개 |
| `spots.json` | 편의시설 41곳, 운영시간, 위치가 확실한지 |
| `offices.json` | 단과대학 행정실 9곳의 건물과 호실. 전화번호는 안 넣었다 |
| `facilities.json` | 운동시설 9곳의 범위 |
| `seed.json` | 분실물 16건, 제보 12건. 발표용으로 만든 예시 |

지도 데이터의 건물 이름이 옛 이름인 게 많았다. 법과대·행정대가 지금은 공공인재대학인 식이다. 18쌍을 지금 이름으로 바꾸는 표를 넣었다.

## 시험

`node --test test/server.test.js` 로 돌린다. 다섯 개다.

1. `server.js` 와 `store/` 는 밖에서 404, `vendor/` 는 200
2. 핀: 정상 201, 같은 글 429, 전화번호 400, 캠퍼스 밖 400, 목록에 기기 번호 없음, 학번 400, 1분에 6번째 429
3. 신고: 같은 기기 두 번째 409, 세 번째 기기에서 숨김
4. 예약: 동시에 두 요청이면 하나만 201, 목록에 닉네임 없음, 남의 예약 취소 403, 하루 세 번째 429
5. 없는 핀 신고 404
