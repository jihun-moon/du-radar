# 짓다에 보낸 요청문

대회 때 짓다 입력창에 넣은 글이다. 입력창이 줄바꿈을 못 받고 별표나 밑줄을 쓰면 글이 깨져서, 한 문단으로 쉼표를 띄워 가며 이어 썼다.
앞쪽 번호는 처음 만들 때 보낸 것이고, 자음과 모음 기호가 붙은 것은 고칠 때 보낸 것이다.

## 3. 지도 데이터 모으기

```text

```
